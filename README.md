# Policy Impact Tracker

The **Policy Impact Tracker** is a data visualization tool designed to measure and display how public policies affect communities at the neighborhood level. Built for civic insight and community advocacy, the app integrates local datasets such as the U.S. Census and Philadelphia 311.

---

## Features

- **Interactive Map:** View impact by census tract or neighborhood.
- **Dynamic Filtering:** Compare policies by year, category, or demographic group.
- **Open Data Integration:** Combines sources like ACS Census data, 311 service requests, and internal tracking systems.
- **Data-Driven Storytelling:** Highlights disparities and opportunities for targeted interventions.

---

## Tech Stack

| Layer | Technology |
